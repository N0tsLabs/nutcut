# OpenMotion Template Spec 0.1

> 一个 OpenMotion 模板是一段**可重复生产的视频**：一个目录（或 ZIP），包含可 seek 的 HTML、参数 Schema、预设、素材、预览与许可证。
> 任何人、任何 Agent 都可以读、改、渲染、再分发。没有账号，没有 Key，没有加密核心。

---

## 1. 目录结构

```
<template>/
  motion.json            # 必需：清单
  params.schema.json     # 必需：参数合同
  presets/default.json   # 必需：默认预设
  src/index.html         # 必需：运行入口
  preview.jpg            # 建议：封面
  preview.mp4            # 可选：预览片
  assets/                # 可选：字体、图片、音频
  LICENSE                # 必需：模板许可
  README.md              # 建议：人类说明
  SKILL.md               # 可选：Agent 专用说明
```

ZIP 只是目录的打包形式；运行时直接读目录。ZIP 必须拒绝路径穿越、绝对路径、符号链接与重复条目。

---

## 2. motion.json

```json
{
  "format": "openmotion-template",
  "specVersion": "0.1",
  "id": "kinetic-title",
  "name": "Kinetic Title",
  "version": "1.0.0",
  "description": "大标题 + 副标 + 强调线的品牌片头",
  "tags": ["title", "brand", "opening"],
  "runtime": {
    "profile": "html/1",
    "entry": "src/index.html",
    "network": false
  },
  "output": {
    "width": 1920,
    "height": 1080,
    "fps": 30,
    "duration": 6
  },
  "params": {
    "schema": "params.schema.json",
    "defaultPreset": "presets/default.json"
  },
  "assets": ["assets"],
  "license": "LICENSE",
  "preview": "preview.jpg"
}
```

### 必需字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `format` | string | 固定 `openmotion-template` |
| `specVersion` | string | 当前 `0.1` |
| `id` | slug | `^[a-z0-9][a-z0-9-]{1,62}[a-z0-9]$`，全局唯一 |
| `name` | string | 展示名 |
| `version` | semver | 模板版本 |
| `runtime.profile` | string | 当前只支持 `html/1` |
| `runtime.entry` | path | 包内相对路径 |
| `output.width/height` | int | 偶数，≤ 4096 |
| `output.fps` | number | 1–120 |
| `output.duration` | number | 秒，> 0 |
| `params.schema` | path | JSON Schema |
| `params.defaultPreset` | path | 预设 JSON |
| `license` | path | 模板许可证 |

### 可选字段

`description`、`tags`、`preview`、`assets`、`author`、`homepage`、`notes`、`capacity`。

未知字段必须保留，不得导致失败；影响执行的未知 `runtime.profile` 必须明确拒绝。

## 3. 运行时合同 `html/1`

模板必须暴露：

```js
window.renderFrame = (frame, inputs) => {
  // 用整数 frame 渲染一帧；不要读 Date.now()、不要依赖上一帧状态
};

window.__ready = true; // 资源就绪后置为 true
```

宿主：

1. 以 `file://` 加载 `src/index.html`；
2. 等待 `window.__ready === true`；
3. 合并 `preset` 与用户 `inputs`；
4. 对 `frame = 0 … ceil(duration*fps)-1` 调用 `renderFrame(frame, inputs)`；
5. 截图 PNG；
6. FFmpeg 编码 MP4。

规则：

- **确定性**：同一 `(frame, inputs)` 必须得到同一帧；随机必须用固定种子。
- **无网络**：`network:false` 的模板不得请求网络；宿主默认断网。
- **无实时时钟**：禁止 `Date.now()`、`performance.now()` 参与画面。
- **无跨帧状态**：每一帧独立可 seek；不得依赖播放顺序。
- **资源就绪**：字体、图片加载完再置 `__ready`。
- **透明**：需要叠加的模板输出透明背景；全屏模板输出不透明背景。

## 4. 参数与预设

`params.schema.json` 使用 JSON Schema 2020-12 的子集：

- `type`: `string | number | boolean | array | object`
- `title`、`description`、`default`
- `enum`、`pattern`、`minimum`、`maximum`、`minLength`、`maxLength`
- `required`（顶层）
- 自定义 `x-capacity`: `{ "maxChars": 24, "maxLines": 2 }`

`presets/*.json` 是一组合法参数值，不是代码。合并顺序：

```
schema defaults → preset → 用户 inputs
```

参数缺失时：有默认值用默认值；没有默认值且 required，必须报错并列出缺失项。

## 5. 素材与容量

- 素材路径必须是包内相对路径；禁止绝对路径与 `..`。
- 图片/字体/音频必须在 `assets/` 下，并在 `assets.json` 记录来源与许可（建议）。
- 文本容量由 `x-capacity` 声明；超长时模板应**分段/分页/缩字号/报错**，不能静默裁切或遮挡。
- 模板应在 `README.md` 写明：支持比例、语言、最长文案、缺素材行为。

---

## 6. 校验与验收

`openmotion validate <dir>` 至少检查：

1. `motion.json` 可解析、必需字段齐全、`format` 正确；
2. 所有引用路径存在且在包内；
3. `params.schema.json` 是合法 JSON Schema；
4. 预设值通过 Schema 校验；
5. 入口存在，浏览器加载后 `window.renderFrame` 是函数；
6. 渲染首帧、末帧、中间帧不报错；
7. 输出尺寸/帧率/时长与清单一致；
8. 无网络请求（如声明 `network:false`）。

发布前建议再跑：

- 3 组不同长度文案（最短/典型/超长）；
- 缺素材场景；
- 竖屏/方屏（若声明支持）；
- 抽帧 contact sheet 人工看一眼。

## 7. 注册表

`registry.json`：

```json
{
  "name": "openmotion-registry",
  "version": 1,
  "templates": [
    {
      "id": "kinetic-title",
      "name": "Kinetic Title",
      "version": "1.0.0",
      "path": "templates/kinetic-title",
      "tags": ["title", "brand"],
      "ratio": "16:9",
      "duration": 6,
      "license": "CC-BY-4.0"
    }
  ]
}
```

Agent 先读注册表，再读模板 `motion.json` 和 `params.schema.json`，不要先执行代码。

## 8. 许可证

- **代码/规范**：建议 MIT。
- **模板**：建议 CC-BY-4.0（署名）或 CC0；商业使用需在 `LICENSE` 明确。
- **字体/音乐/素材**：各自许可，必须单独列出，不得默认随模板再分发。
- 允许 fork、修改、再分发模板；保留署名与许可。

---

## 9. 安全

- 模板是代码：只运行你信任的模板；默认在无网络、只读素材、临时目录中渲染。
- 禁止自动加载 `AGENTS.md`、`CLAUDE.md`、`.cursorrules` 等会提升权限的文件。
- ZIP 读取必须防路径穿越、压缩炸弹、大小写冲突、Unicode 别名。
- 模板不得包含密钥、Cookie、个人路径。

---

## 10. 版本演进

- `specVersion` 0.1 冻结后，新增能力走 `0.2`；
- 模板 `version` 独立 SemVer；
- 破坏性参数变更必须升 major，并提供迁移说明；
- 宿主必须拒绝不支持的 `specVersion` / `runtime.profile`，不能按前缀猜测兼容。
